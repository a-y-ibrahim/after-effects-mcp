# MCP Bridge AE — CEP edition

Обновление `1.14.0-local.2-fast-scenes`: постоянное локальное соединение, карта сцены, пакетная инспекция, два качества превью и проверка глубины мастер-файлов. Настройка EXR, совместимость и сценарии: [FAST-SCENES.md](docs/FAST-SCENES.md).

Основа: [a-y-ibrahim/after-effects-mcp](https://github.com/a-y-ibrahim/after-effects-mcp), версия 1.13.0, commit `e9ffbed9f675a3ac31a4295c83abfd1fb4a7b3f5`.

## Запуск в After Effects

1. Откройте **Window → Extensions → MCP Bridge AE**. Если пункта ещё нет, перезапустите After Effects после сохранения проекта.
2. Дождитесь надписи **Мост активен**, нажмите **Проверить AE**.
3. Подключите MCP-клиент к `build/index.js` из этой папки. Готовая конфигурация — `mcp-config.json`; её также можно скопировать в разделе «Подключение MCP» панели.
4. Начните с `check-bridge`, `run-script` / `getProjectInfo`, `inspect-comp`. Модифицирующие команды используйте в тестовом проекте.

Для локальной неподписанной CEP-разработки After Effects использует `HKCU\Software\Adobe\CSXS.12\PlayerDebugMode = "1"`. На этом компьютере значение уже было включено при установке; установщик его не меняет.

Старую ScriptUI-панель `mcp-bridge-auto.jsx` закройте. CEP-панель должна оставаться открытой во время работы. MCP-сервервер запускается MCP-клиентом через системный Node.js 18+; отдельный запуск `npm start` в терминале не нужен.

## Устройство

- `CSXS/manifest.xml` — dockable CEP-панель для AE 25+ / CEP 12+.
- `cep/index.html`, `cep/css/panel.css`, `cep/js/panel.js` — интерфейс.
- `cep/js/CSInterface.js` — официальный Adobe CEP 12 API, с исходным уведомлением Adobe.
- `cep/jsx/bridge.jsx` — сгенерированные обработчики ExtendScript и изолированный runtime.
- `cep/host-runtime.jsx` — опрос команд, состояние, ограниченный журнал.
- `scripts/build-cep.mjs` — воспроизводимая сборка JSX из исходного моста. Проверяет маркеры перед преобразованием; при изменении структуры upstream завершится ошибкой.
- `src/`, `build/` — исходники и собранный MCP-сервер (61 инструмент, 56 команд моста).

Папка обмена совпадает с исходным сервером: `%LOCALAPPDATA%\ae-mcp-bridge`. Если задан `AE_MCP_BRIDGE_DIR`, одинаковое значение должно быть доступно и AE, и MCP-клиенту.

CEP вызывает `evalScript` последовательно. Опрос запускается страницей CEP; `app.scheduleTask` и ScriptUI-контролы не используются. Закрытие страницы прекращает опрос. Старые команды, находившиеся в папке при загрузке, пропускаются, чтобы не повторить действия предыдущей сессии.

## Локальные изменения

- HTML-интерфейс вместо ScriptUI, пауза/возобновление, проверка AE, журнал, счётчики и конфигурация подключения.
- Исправлена проверка `moveAllAttributes` для precompose нескольких слоёв в сгенерированной CEP-версии.
- Ошибки обработчиков учитываются в счётчике ошибок; ошибка записи результата не скрывается.
- Исходный ScriptUI-мост сохранён в `src/scripts/`; преобразования выполняет сборщик. Установленный ранее файл в папке ScriptUI Panels этой установкой не заменяется.

## Пересборка

В каталоге расширения, с правами записи:

```powershell
npm ci --ignore-scripts
node node_modules/typescript/bin/tsc
node -e "require('fs').cpSync('src/scripts','build/scripts',{recursive:true})"
npm run build:cep
```

После изменения JSX нажмите «Переподключить». После изменения HTML/CSS/JS закройте и откройте панель. После изменения manifest может потребоваться перезапуск AE.
